同一套本机工具，两种用法

连接器各自使用独立身份，访问你选定的资料版本和记忆。

自己的知识库

关联已有 Vault，让常用 Agent 回答时给出文件、章节、行号和版本。保留可以跨助手复用的偏好，随时更正或撤回。

Obsidian · Markdown

小团队的资料库

由一位管理员在本机维护团队的项目手册、交接和复盘。按用途给 Agent 建连接器，集中复核整理提案与引用。

单机 · 单一所有者
运行位置与权限边界

Memoly 在本机保存状态，Web 工作台默认监听 127.0.0.1，MCP 以 stdio 接入本机客户端。当前面向单一所有者，成员账号、远程工作台和企业 SSO 尚未交付。获准返回的片段交给所选 Agent 处理；若它使用云模型，片段可能进入其服务。撤回影响 Memoly 的后续返回，已送达的副本遵循宿主的数据规则。

先跑通一个样例 Vault

这些命令从源码启动，在临时目录复制样例及保存状态。成功后打开终端打印的本机地址。

查看安装包与接入说明 ↗
macOS · Terminal 
git clone https://github.com/stella-dust/memoly.git
cd memoly
npm ci

MEMOLY_DEMO="$(mktemp -d)"
cp -R examples/vault "$MEMOLY_DEMO/vault"
node bin/memoly.js init --vault "$MEMOLY_DEMO/vault" \
  --state "$MEMOLY_DEMO/state" --write-root notes
node bin/memoly.js serve --state "$MEMOLY_DEMO/state"
